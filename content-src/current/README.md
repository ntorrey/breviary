# Current translation

Put the text of the current U.S. *Liturgy of the Hours* here, as `.txt` files in the source format (see `docs/CONTENT-FORMAT.md`). The fill-in-the-blank files from `npm run skeleton` are a good starting point.

This folder is empty on purpose. The current translation is copyrighted (ICEL for the prayers and antiphons, the Grail for the psalms, and various owners for the hymns). Load it only with permission. Before it is committed, the GitHub repository must be private: anything committed here is published by the public GitHub Pages site.

Once this folder has text, the app selects it automatically. It is marked `"default": true` in `edition.json`.
